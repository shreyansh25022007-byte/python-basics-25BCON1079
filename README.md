# Python Basics — 25BCON1079

A small collection of Python programs created during the Python basics coursework.

## What is in this repository?

The repository currently contains six Python programs:

| File | Purpose | Input | Dependencies |
|---|---|---|---|
| `facrorial.py` | Calculates the factorial of a non-negative integer | User input | Python standard library only |
| `fibonacci.py` | Prints the first `n` Fibonacci terms (default `n = 10`) | None | Python standard library only |
| `structure.py` | Demonstrates a class (`FactorialData`) while calculating a factorial | None | Python standard library only |
| `prime.py` | Checks whether an integer is prime | User input | Python standard library only |
| `palindrome.py` | Checks whether text is a palindrome | User input | Python standard library only |
| `student class (OOP Basics).py` | Demonstrates a `Student` class with attributes and prints details | None | Python standard library only |

## Requirements

No third-party packages are required for the programs currently documented here. They use Python's standard functionality.

Recommended Python version: Python 3.

## How to run

From the repository directory:

```bash
python facrorial.py
python fibonacci.py
python structure.py
python prime.py
python palindrome.py
python "student class (OOP Basics).py"
